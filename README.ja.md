# ひとやすみ

画面を暗くしても、AI によるパソコン操作はそのまま。

スクリーンセーバやディスプレイのスリープは、AI によるアプリ操作を中断させることがあります。ひとやすみは、離席後に画面を暗くします。**スリープさせない**をオンにすると、このような中断を防げます。

## 設定

1. Doze.app を開きます。
2. メニューバーの「眯」アイコンをクリックします。
3. **離席時に画面を暗く**をオンにします。
4. 画面を暗くするまでの待ち時間を選びます。初期設定は 10 分です。
5. AI が引き続きアプリを見て操作できるように、**スリープさせない**をオンにします。

戻ってきたら、マウスやトラックパッドを動かすか、キーを押してください。画面の明るさが元に戻ります。動作確認済みの AI ツールによる疑似入力では、明るさは戻りません。他のツールでは動作が異なる場合があります。

**スリープさせない**は自動スリープも防ぎ、ダウンロードや書き出しを継続させます。オンにしても、設定どおりに画面は暗くなります。オプションをオフにするか、ひとやすみを終了すると、以前の設定に戻ります。蓋を閉じたときや、手動でスリープを選んだときの動作には影響しません。

## 対応ディスプレイ

macOS 13 以降が必要です。内蔵ディスプレイと、Studio Display などシステムで明るさを調整できるディスプレイに対応しています。完全に暗くなるかどうかは、ディスプレイによって異なります。
